# Learning Basics

Short practice scripts from the early days of learning Python. Many of them show the same task solved in several ways, which helped me compare approaches.

| File | Topic |
|------|-------|
| `add_two_numbers.py`, `sum_of_two_numbers.py` | Adding numbers with variables, input, functions, `operator`, `lambda` and a class |
| `array_sum.py` | Summing a list with a loop and with `sum()` |
| `max_number.py` | Finding the larger number with `max()`, `if/else` and the ternary operator |
| `factorial.py` | Factorial using a `for` loop |
| `simple_interest.py` | Simple interest formula |
| `compound_interest.py` | Compound interest with `pow()`, `**` and a loop |

Run any of them with:

```bash
python filename.py
```

# Rock Paper Scissors

Play against the computer. Choose `1` (Rock), `2` (Paper) or `3` (Scissors), see the result, and decide whether to play again.

## Run

```bash
python rock_paper_scissors.py
```

## Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock

## Concepts used

`random.randint`, `if/elif/else`, `while` loops, replay prompt.
